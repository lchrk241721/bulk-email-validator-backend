Make.com Integration Guide

Connect your Bulk Email Validator with Make.com workflows

API Endpoints

1. Test Endpoint

GET https://your-domain.com/api/email/make/webhook
Purpose: Verify API connectivity

2. Main Integration Endpoint

POST https://your-domain.com/api/email/make/integration
Content-Type: application/json

Request Format

{
  "api_key": "your_api_key_here",
  "emails": [
    "test1@example.com",
    "test2@example.com",
    "invalid-email"
  ],
  "webhook_url": "https://your-webhook-url.com", // Optional
  "format": "json" // Optional: "json" or "csv"
}

Response Format (JSON)

{
  "success": true,
  "summary": {
    "total": 3,
    "valid": 2,
    "invalid": 1,
    "validity_rate": "66.67",
    "role_accounts": 0
  },
  "results": [
    {
      "email": "test1@example.com",
      "valid": true,
      "checks": {
        "syntax": true,
        "domain": true,
        "disposable": false,
        "roleAccount": false
      },
      "reason": "Valid email address",
      "validation_time": 45
    }
  ],
  "timestamp": "2024-01-15T10:30:00.000Z"
}

Make.com Scenario Setup

Step 1: HTTP Module

  1. Add an HTTP > Make a Request module
  2. Set URL to: https://your-domain.com/api/email/make/integration
  3. Method: POST
  4. Headers: Content-Type: application/json

Step 2: Request Body

{
  "api_key": "{{1.api_key}}",
  "emails": "{{2.emails}}", // From previous module
  "webhook_url": "{{3.webhook_url}}", // Optional
  "format": "json"
}

Step 3: Parse Response

Use the response data in subsequent modules:

  • {{4.body.summary.valid}} - Number of valid emails
  • {{4.body.results[0].valid}} - Validation result for first email
  • {{4.body.results[0].reason}} - Reason for validation status

Example Use Cases

1. Validate New CRM Contacts

Trigger: New contact added to CRM → Validate email → Update contact status

2. Email Marketing List Cleaning

Trigger: Scheduled weekly → Validate mailing list → Segment by validity

3. Lead Generation Pipeline

Trigger: New lead captured → Validate email → Route to appropriate sales funnel

Rate Limits

  • Requests per minute: 60
  • File upload size: 5MB
